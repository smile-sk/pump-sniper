# pump_sniper — бумажный снайпер pump.fun

Проект вырос из замеров 03.11.2026 в `C:\Documents\Projects\ai_ui\tools\`. Здесь он живёт
сам по себе: **денег не тратит, транзакций не отправляет, кошелёк не нужен**. Это прибор,
а не торговый бот.

## Что делает

1. Слушает поток создания токенов pump.fun (публичный WSS, бесплатно).
2. Для каждого нового токена читает bonding curve из блокчейна и записывает **цену во
   времени**: от 0 секунд после создания до конца окна наблюдения.
3. Вход моделируется честно — по цене через N секунд после первого взгляда (столько занимает
   реальная транзакция), причём для НЕСКОЛЬКИХ задержек сразу: 0.5 / 1.5 / 3 / 5 секунд.
   Так видно, сколько стоит нам каждый лишний блок задержки.
4. Выход считается ОДНОЙ пре-регистрированной стратегией — лестницей §4 из `STRATEGY.md`
   (50% x1.5 / 25% x2 / 25% x3, стоп x0.7, таймаут 30 мин). Сетка all-in оставлена только
   разведкой: решение по максимуму из 12–25 ячеек — подгонка под выборку.
5. Комиссии считаются как есть: 1% платформы с каждой стороны + ~0.0001 SOL на транзакцию.

## Файлы

| файл | зачем |
|---|---|
| `sniper_lib.py` | блокчейн-часть: дискриминатор события, PDA по правилу Solana, разбор кривой |
| `strategy.py` | ОДНА модель входа/выхода на прибор и разбор: лестница, скидка на выход, гэп, комиссии, ATA |
| `paper_sniper.py` | один прогон: окно сбора + окно наблюдения + отчёт |
| `run_loop.py` | циклы подряд (ночь), каждый цикл — отдельный процесс |
| `test_strategy.py` | проверки чисел модели (24 штуки), включая контрпримеры из ревью |
| `deploy.py` | залить на VPS, запустить / остановить / показать состояние / забрать лог |
| `data/paper.jsonl` | по строке на токен: полная траектория цены |

## Запуск

```bash
# короткая проба (5 минут сбора, 2 минуты наблюдения)
python paper_sniper.py --seconds 300 --track 120 --poll 3

# ночной прогон на VPS: 10 часов, циклы по 12 мин сбора + 15 мин наблюдения
python run_loop.py --hours 10 --cycle-seconds 720 --track 900 --poll 3 --max-track 150

# управление прогоном на VPS
python deploy.py status
python deploy.py stop
python deploy.py collect
```

## Что мы уже знаем (замерено, не по памяти)

* первый новый токен виден через ~1.6 с после подписки;
* реклама «10–18 в минуту» была ошибкой фильтра — реально **~5–11**;
* с VPS задержка до блокчейна **21 мс** против **66 мс** с дома;
* вход у самой цены создания (дрейф 1.000) — на скорости мы не проигрываем;
* в окне 60 секунд: медианный пик x1.00, до x1.2 дошли 22%, до x1.5 — 11%, до x2 — 0%;
* при таком раскладе все варианты выхода **убыточны** (лучший −3.2% за сделку).

Вывод, ради которого проект и существует: деньги не в скорости входа, а в **отборе монет**.
Ночной прогон собирает данные, чтобы проверить, есть ли у отбора признаки (дев-бай, символ,
время суток, скорость первого роста) или его нет вовсе.

## Чего проект не делает

Не запускает токены, не накручивает холдеров, не рисует объём, не отправляет транзакций.
Если цифры скажут «преимущества нет» — так и будет сказано, и деньги Стаса останутся целы.
